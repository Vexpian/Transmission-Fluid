# References

The textbook covers every technique this challenge needs.

## General

- [IBM Quantum documentation](https://docs.quantum.ibm.com/): Qiskit guides and API reference.
- [Qiskit Aer documentation](https://qiskit.github.io/qiskit-aer/): the simulator.
- M. Nielsen and I. Chuang, *Quantum Computation and Quantum Information*: the standard textbook.

## Scaling

- C. Gidney and M. Ekera, "How to factor 2048 bit RSA integers in 8 hours using 20 million noisy qubits", [arXiv:1905.09749](https://arxiv.org/abs/1905.09749).

## Challenge format

Modeled on the public MIT iQuHACK challenge repositories, such as [iQuHACK/2024_QuEra](https://github.com/iQuHACK/2024_QuEra) and [iQuHACK/2023_Microsoft](https://github.com/iQuHACK/2023_Microsoft).
